# Калькулятор 🧮

Графический калькулятор на Python: современный тёмный интерфейс,
удобный на телефоне. Без сторонних библиотек — только стандартная
библиотека Python.

Математическое ядро (безопасное вычисление через `ast`) сохранено из
консольной версии. Вместо консольного меню теперь запускается
графический веб-интерфейс.

## Возможности

- Кнопки: `0–9`, `+`, `−`, `×`, `÷`, `%`, скобки `( )`, точка `.`, `=`
- `C` — полная очистка, `⌫` — удаление последнего символа (backspace)
- Проценты: `50% = 0.5`, `200×10% = 20`, `200÷10% = 2000`,
  `200+10% = 220`, `200−10% = 180`, `(20+30)% = 0.5`
- Большой экран: текущее выражение + результат
- Ввод выражения целиком: `(2.5 + 3) × 4 ÷ 2`
- Ввод с клавиатуры: цифры, `+ - * / % ( ) .`, `Enter` (=), `Backspace`, `Esc` (C)
- Компактная кнопка «🕘 История» сверху — история открывается
  отдельной панелью поверх калькулятора (до 50, сохраняется в браузере)
- В панели истории: кнопки закрытия (`✕` / «Закрыть») и «Очистить»;
  клик по записи возвращает выражение обратно в калькулятор
- Обработка деления на ноль и неправильных выражений
- Адаптивная вёрстка для экрана телефона (до 430px)
- Десятичные числа через точку или запятую: `2.5`, `2,5`
- Унарный минус/плюс: `-5 + 3`

## Файлы

- `calculator.py` — математика (`calculate`, `expand_percent`,
  `format_result`, ...), веб-GUI (`run_gui`, `CalculatorHandler`, `HTML_PAGE`)
  и точка входа
- `test_calculator.py` — автоматические тесты (включая `TestPercent`)

## Требования

- Python 3.8+ (без сторонних библиотек, `tkinter` не нужен)
- Браузер (Chrome / Safari / любой на телефоне)

> Почему веб-интерфейс, а не Tkinter? На телефоне (Android/Termux)
> модуль `tkinter` обычно недоступен, а веб-страница одинаково хорошо
> выглядит на телефоне и на компьютере.

## Запуск графического интерфейса

Из папки проекта:

```bash
python calculator.py
```

или:

```bash
python3 calculator.py
```

Откройте в браузере адрес из консоли, например:

```text
http://127.0.0.1:8000
```

На телефоне удобнее всего запускать и открывать этот же адрес
в браузере телефона.

Дополнительные опции:

```bash
python calculator.py --port 8080      # другой порт
python calculator.py --no-browser     # не открывать браузер автоматически
python calculator.py --host 0.0.0.0 --port 8000   # доступ с других устройств в LAN
python calculator.py --cli            # консольный REPL-режим
```

## Как пользоваться

1. Нажимайте кнопки или печатайте выражение в верхнем поле.
2. `=` — вычислить. Результат крупно показывается на экране
   и подставляется обратно в поле ввода для цепочки вычислений.
3. `C` — очистить всё, `⌫` — стереть последний символ.
4. Кнопка «🕘 История» сверху открывает панель поверх калькулятора.
   Клик по записи возвращает её выражение в ввод и закрывает панель.
   Кнопки «Очистить» / «✕» / «Закрыть» управляют панелью.
5. Сетка кнопок адаптирована для телефона: верхний ряд
   `C ( ) %`, далее цифры с `÷ × − +`, `⌫` рядом с `0/.`,
   большая кнопка `=` на всю ширину внизу.

Примеры выражений:

```text
2 + 3 * 4
(2 + 3) * 4
10 / 4
(2.5 + 3) * 4 / 2
-5 + 3.2
50%
200+10%
200-10%
200*10%
(20+30)%
```

Ошибки показываются красным прямо на экране:

- `5 / 0` → «Ошибка: деление на ноль!»
- `2 + * 3` → «Ошибка ввода: ...»

## Запуск тестов

```bash
python -m unittest test_calculator.py -v
```

или:

```bash
python test_calculator.py
```

или:

```bash
pytest test_calculator.py -v
```

Тесты покрывают: базовые операции, приоритет, скобки, десятичные числа,
унарные знаки, символы кнопок `× ÷ −`, проценты (`50%`, `200+10%`,
`200-10%`, `200*10%`, `(20+30)%`, ошибки `%`), деление на ноль,
некорректный ввод, форматирование результата, историю и HTTP API
(`/`, `/api/calculate`, проверка вёрстки истории и `%`).

Все тесты должны завершиться со статусом `OK`.

## API (для разработчиков)

Веб-интерфейс использует JSON API:

```bash
curl -X POST http://127.0.0.1:8000/api/calculate \
  -H "Content-Type: application/json" \
  -d '{"expression": "(2 + 3) × 4"}'
# {"ok": true, "result": 20.0, "formatted": "20", "expression": "(2 + 3) × 4"}
```

Проверка состояния:

```bash
curl http://127.0.0.1:8000/health
# {"status": "ok"}
```
